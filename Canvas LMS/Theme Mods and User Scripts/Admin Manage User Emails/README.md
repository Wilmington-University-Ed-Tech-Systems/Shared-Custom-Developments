# Admin Manage User Emails

This feature will add the ability for admins to manage a user's emails from the user account details page (typically accessed from finding a user through People search of an admin account). This allows you to view all email communication channels for the user. It allows you to change the default email address. It provides the ability to confirm an unconfirmed email address with the click of a button (accomplished by deleting and then re-adding it as confirmed). Finally, it allows deleting an email address.

WARNING: The Canvas API does not include details about which communication channel is an institutional email address (set by SIS Import). This also means that when deleting an email, it doesn't follow the account setting to prevent deleting an institutional email address.
